# 기존 로컬 변경의 main 통합

사용자 지시: 남아 있는 변경을 Git에 push. 작업 브랜치 `feat/publish-pending-mobile-ui-20261024`, 기준 main `61c0cada1b66d38858577690438502e353df217c`. 같은 버전의 `COLLABORATION.md` 원문을 확인하고 독립 작업 폴더에서 통합했다. 원래 작업 폴더의 미커밋 변경/생성 자료/복구 백업은 보존한다.

- WireGuard/ADB 폰 제어와 Instagram/Edits 릴스 게시용 로컬 CLI, 기기·한 번의 공유·불명 결과 보존과 관련 테스트/사용 문서.
- 제작·수집 작업자가 없는 게시물 준비/레퍼런스 계정 관리 서버와 API, 현재 계정 목록 추가.
- 전체 보기/완성/제작 중 필터 및 검색·상태 갱신 연계.
- 무손실 편집 master를 보존하면서 전달 final을 H.264 Main@4.0/yuv420p/AAC-LC/+faststart로 만드는 경로. 모바일 전송도 별도 High 프로파일 대신 같은 `encode_delivery`를 사용한다.

관련 Python 92개가 최초 통합 상태에서 통과했고, 모바일 인코더 통합 후 해당 모바일/썸네일 22개(새 실제 변환 검사1개 포함)도 통과했다. Node 화면 관련 17개와 JavaScript 구문 검사가 통과했다. 실제 짧은 영상 변환에서 Main 프로파일·레벨·원본/음성 보존·전체 디코드를 확인했다.

실폰 ADB 연결/앱 화면/영상 전송/실제 게시의 검증 완료를 뜻하지 않는다. 폰 IP/ADB 포트/개인 경로/DB/세션/생성 미디어/복구 백업은 이 커밋에 포함하지 않는다. 이 통합으로 서비스·제작·수집·예약을 재시작하거나 폰을 제어하지 않았다. 기존 main의 협업/PC별 로컬 저장 지침과 DM 문구/개별 복사 기능은 보존했다. 실질적인 내용 소실이나 필요한 추가 동의는 없다.
