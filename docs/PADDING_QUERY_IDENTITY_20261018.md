# 핵심 제품 검색 계약 수정 및 몽벨 검색어 생성 검증

2026-10-18. 사용자 요청 범위는 규칙 업데이트와 몽벨 검색어 재생성 검증이다. 실제 플랫폼 검색·다운로드·TTS·영상 재제작은 수행하지 않았다.

## 변경한 규칙

주제의 최소 제품 정체성을 먼저 정하고 언어별 제품 명사와 필수 조건을 생성·독립 검수·전송·실제 검색 횟수 집계에 함께 적용한다. 브랜드·모델이 중심이면 고정하고, 브랜드가 없으면 제품 종류와 주제의 핵심 특징을 고정한다. 일반 제품 주제에 브랜드·특징을 만들지 않으며 배경 로고도 중심 브랜드로 승격하지 않는다. 확인한 부가 특징만 검색 변형에 사용한다.

몽벨 패딩은 몽벨+패딩을 고정한다. 칼라·퀼팅·앞 지퍼·주머니·길이는 변형 조건이다. 접이식 국자처럼 브랜드 없는 주제는 접이식+국자를 고정한다. 모든 레퍼런스 특징을 매 검색어에 나열하거나 동일 장면과 대사를 일치시키는 규칙은 아니다.

핵심 조건이 빠진 일반 제품·리액션 검색은 핵심 최소5/5에 포함하지 않는다. 같은 브랜드 표기·제품 동의어·어순·검색 인덱스 연산자만 다른 검색어는 중복이다. 영어와 중국어의 의미가 같은 번역은 각 언어의 실제 검색으로 각각 인정한다.

## 구현

- `source_query_identity.py`: 독립 검토·문자 그대로의 원문 인용 또는 실제 시각 관찰에 결속된 제품/필수 조건, 검색어 검사, 동의어·브랜드 표기·어순 중복 판정.
- `source_visual_queries.py`: 새 `sampled-product-search-v4-core-identity` 계약으로 제안과 독립 검토를 수행하고, 핵심 조건을 보존한 검색어만 실제 전송용 풀과 최소5/5에 포함한다. 이전 v2/v3 영수증은 변경 없이 검증하며 새 캐시와 분리한다.
- `source_finder.py`, `source_search/{planner,discovery,strategy}.py`, `browser_search.py`, `source_browser_worker.py`, `youtube_search.py`, `source_coverage.py`: 전송과 worker 경계, 남은 검색 횟수, 실제 검색 영수증에도 같은 계약을 전달한다. 과거 일반 패딩 검색만으로 몽벨 검색 최소치가 채워졌다고 조기 종료하지 않는다.
- `AGENTS.md`, `source_video_pipeline.md`, `CODE_MAP.md`를 갱신했다.

## 실제 생성 중 발견한 문제와 보정

첫 생성은 모든 검색어에 몽벨을 넣었지만 독립 검토가 실패했다. 검수기가 레퍼런스의 ‘경량’까지 모든 검색어의 필수 조건으로 확대했고, 중국어 번역을 영어와의 중복이라고 오인했다. 제안의 중국어 `蓬松夹克`도 자연스러운 제품 검색어로 승인되지 않았다.

첫 제안/검토는 `data/source-visual-queries/b0e91b37a8ed9b599c67d02341ca87f1ca5bc39eab034817590ba2dcb0d952f7/`에 보존했다. 승인 값을 수동으로 바꾸지 않았다. ‘주제를 식별하는 최소 고정 조건’과 ‘변형할 부가 특징’을 명시하고 언어별 집계를 분리했으며, 실제 퀼팅 구조를 나타내고 충전재를 단정하지 않는 자연스러운 중국어 명사를 사용하도록 수정했다. 수정된 프롬프트 계약 `minimal-core-natural-terms-v2`는 별도 캐시 키를 사용한다.
