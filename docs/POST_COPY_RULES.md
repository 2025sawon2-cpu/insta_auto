# 게시물 본문·고정댓글 작성 규칙

2026-10-22 사용자 추가 요청을 반영한다. 이 규칙은 터진게시물의 **게시물 준비용 본문/고정댓글**에 적용하며 영상 낭독 대본·TTS를 다시 만들거나 변경하는 지시가 아니다.

## 인스타 본문

- 30~40대 여성 독자가 공감할 생활 속 구체적인 불편·상황으로 시작한다. 나이와 성별을 문장에 직접 나열하거나 모든 독자의 생활을 단정하지 않는다.
- 짧은 영상 대본을 그대로 옮기는 데서 끝내지 않는다. 사용 장면, 편해지는 동선, 정리·코디·시간·공간 활용 등 제품별 이득을 구체적으로 설명한다. 보통 500~900자 안팎을 지향하되 제품 정보가 충분한 범위에서 자연스럽게 작성하고 분량을 채우기 위한 반복은 피한다.
- 대본 밖의 설명과 활용 상황을 추가할 수 있다. 확인된 제품 특징으로부터 기대할 수 있는 편의를 자연스럽게 풀어 쓰되 확인되지 않은 성능·가격·효과·구성품을 지어내지 않는다. 직접 사용·구매·테스트한 근거가 없으면 ‘직접 써보니’, ‘사서 사용했다’, 사용기간·가족의 실제 반응 같은 체험담을 사실처럼 쓰지 않는다.
- 공감 도입 → 구체적 장점과 활용 → 일상에서의 가치 → 댓글 안내 → 관련 해시태그 순서가 기본이다. 읽기 편하게 문단을 나누고 적당한 기호와 이모지를 쓴다. 관련 없는 구매 유도나 근거 없는 발송 약속을 넣지 않는다.
- **맨 마지막 줄에 해당 주제와 관련된 해시태그를 정확히 5개** 둔다. 해시태그 뒤에 다른 문장을 붙이지 않고 본문 중간에도 추가 해시태그를 넣지 않는다.

## 고정댓글

이모지를 포함한 두 줄을 기본으로 한다. 첫 줄은 제품/주제의 핵심 장점 한 줄, 둘째 줄은 정확한 댓글 키워드 안내다.

```text
✨ 벽에 구멍 없이 변기 위 빈 공간을 수납으로 활용해요.
💬 댓글에 "나도" 남겨주세요.
```

기본 생성 문구는 이 형식을 따른다. 사용자가 화면에서 직접 편집한 초안을 강제로 교정하거나 저장을 막지 않는다. 계정·썸네일 선택·제품 링크 및 다른 직접 수정 내용은 문구 갱신과 별개로 보존한다. 실제 인스타 업로드·댓글 게시는 연결하지 않는다.

## DM 준비 문구 (2026-10-23)

DM 메시지는 모든 게시물에 아래 고정 문구를 제공한다. 줄바꿈과 아래 방향 이모지 8개를 그대로 복사하며 화면에서는 읽기 전용이다.

```text
본 포스팅은 쿠팡파트너스 활동의
일환으로 제품 구매시 일정액의 수수료를
지급 받습니다!
👇👇👇👇👇👇👇👇
```

DM 버튼 문구는 확인된 게시물 주제를 후킹하는 공백 포함 20자 이내 한 줄이다. 기존 30개 게시물에 주제별 문구를 제공하고 직접 수정한 값은 초안에 보존한다. 알 수 없는 게시물은 저장된 주제 문구만 사용하며 상품 특징을 새로 만들지 않는다. 본문·고정댓글·제품 링크·DM 메시지·DM 버튼 문구에는 각각 현재 입력을 복사하는 버튼을 제공한다. 사용자 후속 요청에 따라 썸네일 4안에는 복사 버튼을 두지 않고 문구 수정과 영상 반영 기능을 유지한다. 이 준비 기능은 DM 발송이나 자동화 연결을 실행하지 않는다.
