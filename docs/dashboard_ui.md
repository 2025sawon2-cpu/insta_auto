# 대시보드 화면 구성

- `/`는 게시물, 현재 설정 요약, 상위 주제 카테고리와 접이식 검색창을 표시한다.
- 메인 상단 안내는 ×로 닫는다. 같은 내용은 이 브라우저에서 새로고침·상태 조회 후에도 숨김을 유지하며 새로운 수집 결과나 다른 문제가 생기면 다시 표시한다. 정상 수집 기록은 중립적인 안내로 표시하고, 경고에는 원인에 맞는 해결 방법과 링크를 함께 제공한다. 관리 대상에서 제외된 계정의 과거 실패는 현재 오류로 표시하지 않는다.
- 계정관리의 `수집 문제 해결 방법`에는 로그인·인증, 계정 접근, 요청 제한, 수집 지연, 서버 연결별 조치와 실행 명령 복사 버튼이 있다. 복사는 실행이 아니며 수집 서버 PC에서 사용자가 실행한다.
- `/settings.html`에서 감지일·기간·유형·등급·정렬·판정 상태·계정 필터, 판정 프리셋과 세부 기준을 저장한다. 판정 방법과 플랫폼 로그인 관리도 이 페이지에 있다.
- 표시 조건은 `/api/display-settings`를 통해 SQLite `app_meta`에 저장한다. 같은 서버를 보는 브라우저는 같은 조건을 사용한다. 검색어와 클릭한 주제는 임시 상태다. 서로 다른 PC의 서버끼리는 설정이 자동 공유되지 않는다.
- 판정 기준은 기존 `/api/criteria`로 저장·재분석한다. 표시 조건은 점수를 바꾸지 않는다.
- `/accounts.html`의 계정 카드에 기존 관리 지표와 평소 성과·핫 게시물 수·팔로워 대비 제작 후보를 한 번씩 표시한다. 수집 전 계정에는 분석 결과 없음이 표시된다.
- 알림은 기본적으로 종 아이콘과 전체 미확인 개수만 표시한다. 패널을 열어 개별 읽음 표시와 읽은 알림 삭제를 할 수 있다. 패널을 여는 것만으로 읽음 처리하지 않는다. 삭제 API는 읽은 항목만 삭제하며 미확인 항목을 보존한다.
- 카테고리는 `categories.py`에서 캡션과 해시태그의 구체적인 주제어로 분류한다. 가장 근거가 많은 상위 카테고리 하나를 사용하며, 동점은 정의 순서로 정한다. 근거가 없는 경우 `생활·기타`로 표시한다. 감정·상황 단어를 독립 주제로 만들지 않는다. 결과는 리포트의 게시물별 `categories`와 `topics`에 함께 반영된다.

검증: `tests/test_dashboard_settings.py`는 API 저장·검증·알림 삭제 범위를,
`tests/test_dashboard_browser.py`는 화면 이동·설정 유지·검색·카테고리·알림과 모바일 너비를 확인한다.

- 목록은 썸네일·계정명·원본 조회수(사진은 좋아요)·평소 대비 성과와 제작 상태를 표시한다. 게시글 본문과 중복 제작실 링크·긴 진행 설명은 목록에서 제거한다. 하단의 제작 보기/완성 영상 보기와 원본 보기로 이동한다.
- 카드 제작 상태는 `제작중`, `완성`, `확인필요` 세 가지다. 제작중은 카드 테두리를 따라 강조색이 순환하고, 완성은 녹색, 확인필요는 주황색으로 표시한다. 움직임 줄이기 설정에서는 순환 효과를 멈춘다. 제작중에는 실행·자동 재시도·대기를 포함하며, 중지·오류·자료/설정 준비·사용자 검토가 필요하면 확인필요로 표시한다. 제작 작업이 없는 게시물에 가짜 진행 효과를 붙이지 않는다. 과거 완성본이 있어도 새 제작이 시작되면 현재 작업 상태를 표시한다.
- 게시물을 클릭하면 상세 팝업의 영상 정보가 추가 클릭 없이 바로 표시된다. 캡션은 상세에서 보존한다. 조회수·좋아요·댓글은 한 줄 3칸으로 표시하며, 기본 정보는 처음 발견한 시각·팔로워·비교 게시물 수만 작은 한 줄에 모은다. 반응 성숙도·신뢰도·보정 전 배수·판정 참고·성장/추적 진단은 사용자용 상세에서 제거한다. 분석 데이터와 추천·추적 로직은 바꾸지 않는다.
- 소스·대본·음성·완성영상 결과 버튼과 영상 보기·다운로드·제작실 수정 버튼은 항상 표시한다. 준비되지 않은 결과는 버튼을 비활성화하고 바로 아래 또는 버튼 안에 작업중·설정 확인·미등록 등 이유를 표시한다. 자료가 도착하면 자동으로 활성화하며, 소스가 일부 확보됐으면 그 결과부터 열 수 있다. 완성 영상이 있어도 다운로드 URL이 없으면 다운로드만 비활성화한다. 새 제작 중에도 이전 완성본의 재생과 다운로드는 유지한다.
- 개별 영상 후보 찾기·ZIP 다운로드와 원본 대사/화면 글자 추출은 게시물 상세에서 제거하고 제작실 상세 하단의 접힌 `보조 도구`로 옮긴다. 원본이 없는 내 촬영 작업에는 표시하지 않는다. 도구를 펼치는 것만으로 작업을 시작하지 않으며, 결과는 현재 제작의 소스·대본에 자동 반영하지 않는다. 같은 작업의 상태 갱신·탭 전환에서는 진행 상태·펼침·다운로드 결과를 유지한다.
- 핫 주제 옆 `현재 보기` 카드는 실제 필터 결과 수와 기간을 숫자로 강조한다. 정렬·유형·등급은 아이콘 배지로, 전체 조건과 3단계 등급 기준은 펼칠 수 있는 세부 조건으로 표시한다. 검색·주제 변경 시 개수와 적용 범위를 함께 갱신하며, 모바일에서는 주제 아래로 배치한다.
