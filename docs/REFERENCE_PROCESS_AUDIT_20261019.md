### 1. 실제 레퍼런스와 짧은 주제 힌트 사이의 상충 지시

- 현상/원인: `source_visual_queries.py`의 생성·독립검토 프롬프트가 실제 설명/픽셀의 제품 구조를 우선하라고 하면서, 뒤에서는 특정 패딩 예시와 짧은 hint만으로 필수 특징을 결정하도록 지시했다. 실제 잘못된 제품 통과를 이번에 재현했다는 뜻은 아니다.
- 수정: 특정 예시의 '브랜드+제품이면 충분' 판정을 제거하고, 해당 레퍼런스의 중심 설명과 실제 픽셀에서 최소 정체성을 도출하도록 정렬했다. 부가 색상/주머니 등은 실제 주제에서 제품을 구별할 때만 필수다. 새 프롬프트 revision은 캐시 키에 포함한다.
- 보호: 승인된 명사·실제 제품 정체성·독립 검토·검색 실적 계약은 유지. 예시를 다른 제품의 규칙으로 사용하지 않는다. 기존 영수증 검증/이력은 보존한다.
