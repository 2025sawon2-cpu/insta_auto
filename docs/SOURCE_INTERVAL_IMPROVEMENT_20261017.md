## 구현

2. `source_batches.py`에도 같은 경로를 연결했다. 새로 받은 묶음을 검토한 뒤 분량이 부족하면 다음 다운로드에 앞서 받은 파일을 먼저 복구한다. 사용자 제외·실제 파일 SHA·현재 작업/원본/제품/본문을 재확인한다. 충분하면 정지한다.
3. 미세한 시간값을 바꿔 같은 실패를 반복하지 않는다. 방법키는 실제 포함 native 프레임 범위·원본/레퍼런스 SHA·제품 맥락에 결속한다. 작업 체크포인트는 제안 전체 SHA와 구간 영수증 SHA를 보존한다. 중단 원인 미확인/실제 파일·영수증 불일치는 근거 대기로 남기고, 형식 오류·정상 거절·서비스 대기를 구분한다. 폴더명/UUID/시간 오차만 바뀌어도 새로운 승인 기회가 생기지 않는다.
4. 움직이는 문자 위치를 희소 프레임 사이에서 추측해 마스크를 보간하지 않았다. 짧은 승인 범위 안에서만 해당 범위의 마스크가 활성화되며 기존 renderer의 시간 경계를 유지한다. 따라서 서로 다른 위치의 글자를 긴 4초 전체에 동시에 가리는 문제를 짧은 명시 구간으로 줄일 수 있다. 모든 구간에서 가림 면적 감소를 보장하는 방식은 아니다.
5. `shot_presentation.py`/`scene_analysis.py`는 같은 의미 관련성의 후보들 사이에서 실제 프레임에 결속한 구도·선명도·제품 노출·제품 가림 면적을 순위에 반영한다. 대본과 반대인 동작/다른 제품을 통과시키지 않으며 대안도 삭제하지 않는다. 명확한 대안이 없다고 임의의 화질 점수로 제작을 막지 않는다.
