## 원인

1. **이번 재제작은 기존 실패 job의 source_ids 그대로였다.** 세 작업 모두 편집 입력3개를 유지하고 인접 구간 검토/재사용으로 중단을 해소했다. 소스를 새로 다양하게 수집한 실험은 아니었다. 손난로 task의 총5레코드 중 부적합2개는 편집 입력에서 빠졌다.
2. **수집 종료는 사용 가능한 양과 핵심 장면 위주다.** 최초 수집은 저장v3의1.25배/핵심4초, 새 정책v4는 이를 권장량으로 두며 핵심 구간이 있으면 배치로 넘어간다. TikTok5개는 선호 목표다. 현재 최종 영상의 서로 다른 원본 수나 한 원본 점유율을 기준으로 다양성 보완을 요청하지 않는다. 이는 3/2/1이라는 하드 제한을 둔 것이 아니다.
3. **선택기는 실제 제품 근거·화질·직접성·새 정보에 가점을 준다.** 반복 비용은 있지만 원본별 사용 분산을 직접 최적화하지 않는다. 한 원본의 여러 shot은 서로 다른 visual cluster로 취급될 수 있어 같은 원본이 계속 선택될 수 있다. `studio_story_selection.py`의 비용식에 product가 아니면 길이×0.5 비용, 직접성 비용, 새 정보 보상 등이 있다.
4. **손난로의 다른 승인2개는 이야기 맥락에만 제한적으로 후보가 됐다.** 최종 timeline beat1/2에는 분홍 손난로 shot이 실제 options에 있지만 solver는 주제품 shot을 선택했다. beat3~15에서는 다른 제품 외형을 주제품으로 오인시키는 후보로 제외돼 주제품 shot들만 남았다. 모든 후보를 renderer가 못 읽은 오류나 수집 파일 전체 소실 문제는 아니다.
5. **플랫폼 확장도 충분하지 않았다.** 최초 텐트·가방 manifest에는 YouTube 등 일부 플랫폼을 login_required로 미시도한 기록이 있다. 손난로 최초 확보12개는 전부 보관 파일 재사용이다. 이는 당시 실행 기록이며 현재 브라우저에서도 접근 불가라는 결론은 아니다. 현재 로그인/탭 재점검은 이번 읽기 전용 조사에서 실행하지 않았다.

## 판단과 다음 개선 범위

이번 변경은 승인된 적은 소스로도 제작 중단을 해소한 결과다. 동일 제품의 다양한 실제 소스 확보와 균형 있는 배치까지 개선했다고 설명하면 부정확하다. 특히 가방88.5%·손난로100%의 한 원본 집중은 개선 대상으로 남는다.

다음에는 이미 확보한 적합한 다른 원본·미검토 자료를 먼저 확인하고, 실제 사용 가능한 범위에서 서로 다른 원본의 장면을 선호하도록 수집 종료와 선택 점수를 연결할 필요가 있다. 핵심 제품이1개뿐이면 확인된 제품명으로 기존 세션의 미사용 검색 범위를 보완하고, 충분한 관련 소스가 없으면 반복을 허용한 채 완성한다. 최소 개수 강제로 다시 제작을 막거나 관련 없는 재킷·과일·다른 제품 시연으로 수를 채우지는 않는다. 이번 질문을 구현 승인으로 간주해 자동 재제작하지 않았다.
