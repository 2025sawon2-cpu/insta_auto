## 설치별 초기 설정

`web/setup.html`은 내 게시용 인스타 계정(다중 선택), 별도 수집·댓글용 인스타 계정,
내 쿠팡 인플루언서 공개 스토어 주소, 상품 등록 컬렉션을 저장한다. 수집 계정을
비우면 첫 게시용 계정을 사용한다. 비밀번호·API 키·쿠키는 입력받지 않으며 기존
Chrome 로그인은 사용자가 준비한다. 저장은 설정 완료만 뜻하고 실제 로그인·스토어
소유 확인은 작업 실행 직전에 수행한다. 화면·API는 인증 성공으로 표시하지 않는다.

초기 안내는 저장된 연결 정보·현재 열린 Chrome 탭을 먼저 재사용하고, 빠진 서비스만
같은 기존 Chrome 프로필에서 열도록 안내한다. Instagram(상품 확인용), 리틀리 DM
자동화(게시용 인스타 연결), 쿠팡 인플루언서 ‘내 스토어’를 포함한다. 폰 Instagram·
Edits의 게시 계정은 웹의 상품 확인 계정과 구분한다. 비밀번호·인증 코드는 받지 않는다.
실제 대조·누락 처리 절차는 [모바일 업로드 초기 확인](MOBILE_REELS_WIREGUARD.md#초기-설정과-실행-전-확인)이 원본이다.

독립 게시용 서버의 신규 설치는 `/`에서 초기 설정으로 안내한다. 기존 설치는 로컬
자동화 설정·저장된 초안의 계정과 역사적 Studio 계정 목록을 읽어 미리 채우며, 초안·
작업 이력을 변경하지 않는다. 메인 상단과 설정 페이지에서도 다시 열 수 있다.
`GET /api/installation`과 같은 출처의 로컬 `PUT /api/installation`을 사용한다.
공개 Cloudflare 공유 화면은 읽기 전용이다.

설정은 Git 제외 `data/monetization/state.sqlite3`의 `configuration.installation`에
버전 비교로 저장한다. 게시물 준비의 계정 목록과 수익화/수집의 계정·스토어·컬렉션
설정에 반영하되, 기존 활성화 여부·Chrome 결속은 유지한다. 저장 자체는 작업자·
댓글·DM·등록·예약을 시작하지 않는다. 실행 중이거나 결과가 불명인 작업, 상품 확인
대기열, 진행 중인 원링크 작업이 있으면 연결 변경을 거부한다. 기존 스토어 이력이
있는 설치를 다른 소유자의 스토어로 바꾸는 기능은 제공하지 않으며 다른 사용자는
별도 설치·데이터 폴더를 사용한다.
