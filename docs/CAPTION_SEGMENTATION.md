# 대본의 의미 단위를 지키는 자막 분할

이 문서는 낭독 대본을 화면 자막 조각으로 나누는 현재 원본이다. TTS 입력을 여러 번 합성하도록 나누는 규칙이 아니다. 대본의 단어 사이 띄어쓰기와 화면에서 다음 자막으로 넘어가는 경계를 구분한다. 선택 대본의 문구·순서·띄어쓰기·음성을 임의로 바꾸지 않는다. 화면 문장부호 정리는 기존 표시 규칙을 따른다.

기존 `docs/studio.md`와 `docs/editing_adapter.md`, Auto CapCut의 `docs/shortform_house_style.md`에 실제 글꼴 폭과 자연스러운 의미 단위 기준이 이미 있었다. Auto CapCut의 `subtitles.py`와 회귀 검사에는 실제 수동 편집에서 확인한 의존명사·부사 보호도 있었다. 아래 규칙은 그 기준을 구체화하고 유한 점수에 의한 선호를 실제 검사와 연결한 것이다.

## 자르기 전에 할 의미 검토

현재 원고 전체와 이 문서를 읽고 제품·명사구, 시간 표현, 의존명사, 보조용언, 수량·단위, 부사·서술어의 연결을 검토한다. 제품명·일반 명사구는 단어 목록만으로 모두 알아낼 수 없으므로 원고별로 함께 읽어야 하는 표현을 원문 위치·인용·이유가 있는 `protected_spans`로 명시한다. 해당 표현이 없다는 판단도 검토에 남긴다. 형식에 맞는 검토자 이름이나 빈 목록만으로 의미 검토 완료를 대신하지 않는다. 사용자에게 매번 중간 승인을 받는 절차가 아니라 현재 제작 담당자가 수행하는 내부 검토다.

분할 결과의 각 경계에는 무엇이 끝나고 무엇이 시작되는지, 이어 읽어야 하는 표현을 끊지 않았는지 이유를 남긴다. 특정 글자 수나 폭 안에 들어온다는 설명만으로 의미 검토를 끝내지 않는다.

## 함께 읽어야 하는 표현

| 종류 | 보호 원칙과 예시 |
|---|---|
| 제품·명사구 | 같은 대상을 가리키는 한 묶음은 붙여 표시한다. `누빔 / 텐트가` 대신 `침대 둘레를 / 누빔 텐트가 감싸고`처럼 주변 경계를 조정한다. 다른 제품에도 원고별 보호구를 지정하며 ‘누빔’만 예외 목록에 넣어 해결하지 않는다. |
| 시간 표현 | `잠들기 전`, `사용한 후`, `세 시간 뒤`처럼 행동·시간과 전후 관계를 함께 읽는다. `잠들기 / 전 앉아 쉬기도 좋고`처럼 관계어를 다음 자막에 홀로 남기지 않는다. `전`이라는 글자가 나왔다는 이유로 다른 뜻까지 일괄 결합하지 않는다. |
| 의존명사 | `할 수`, `쓰는 것`, `한 적`처럼 앞말과 연결되는 의존명사를 떼어 다음 자막 첫머리에 남기지 않는다. 앞뒤 문맥으로 실제 연결을 확인한다. |
| 보조용언 | `주고 싶다`, `하지 않아요`, `써 보면`처럼 한 서술을 이루는 표현을 불필요하게 갈라 놓지 않는다. |
| 수량·단위 | `한 잔`, `세 개`, `삼 초`, `500 mL`처럼 수치와 그 단위를 보존한다. 수식하는 말이나 단위가 혼자 남지 않도록 한다. |
| 부사·서술어 | `딱 잠가야`, `완전 신기하다고`, `잘 어울리고`, `더 머물고 싶은`처럼 다음 말에 기대는 표현을 검토한다. 문맥과 무관하게 모든 부사 뒤를 영구 금지하는 것으로 확대하지 않는다. |

문장 종결·자연스러운 절 경계에서 우선 나눈다. 화면을 꽉 채우려는 이유로 보호구를 끊거나, 읽을 수 없는 짧은 꼬리만 따로 표시하지 않는다. 앞쪽 자막을 짧게 하거나 주변 구절을 다시 묶을 수 있다. 사용자가 지정한 줄바꿈도 의미·보호구 검사와 충돌하면 묵살하거나 강제 통과시키지 않고 충돌 근거를 남긴다.

## 화면 폭·원문·시간축

- 현재 계획에 결속한 실제 글꼴·크기·폭을 사용한다. 기존 기본 폭은 1080×1920 화면에서 900px이며, 이를 맞추기 위해 글자를 줄이거나 원고를 요약하지 않는다. 고정 글자 수로 대신 계산하지 않는다.
- 보호구 자체가 폭을 넘으면 의미 없는 중간 절단으로 통과시키지 않는다. 조정이 필요한 표현과 실제 측정 폭을 기록하고 같은 원고의 분할 계획을 다시 검토한다. 일반적으로 긴 단어를 표시 폭에 맞춰 나누던 과거 기능을 보호구 우회 경로로 사용하지 않는다.
- 분할된 자막을 순서대로 이었을 때 선택 대본의 내용이 빠지거나 추가되지 않아야 한다. 표시에만 생략하는 문장부호와 원고 수정은 구분한다. 다른 연결의 의미를 만들도록 단어를 재배열하지 않는다.
- 의미 단위를 먼저 정하고 현재 음성의 실제 단어 시각에 자막을 결속한다. 화면 컷 길이에 맞춰 대사를 쪼개거나, 새 분할에 옛 자막 시각을 그대로 복사하지 않는다. 시간 정보가 불확실하면 미확인으로 남기며 문자 수 비례를 실제 발화 시각이라고 주장하지 않는다.

## 실행에서 강제할 계약

Auto CapCut은 이 원문을 파일로 읽고 아래 정책 ID·버전 및 실제 문서 SHA를 사용한다. Hotpost 패키지를 직접 import하지 않으며 기존 버전 JSON·별도 프로세스 경계를 유지한다. 독립 배포에서는 같은 원문 파일의 명시 경로를 설정한다. 문서가 없거나 정책을 파싱할 수 없으면 문서를 읽었다고 가정해 계속하지 않는다.

새 분할에는 원고, 문서, 실제 글꼴·배치, 보호구, 분할 목록과 경계별 검토를 결속한다. 새 분석·사진 영상·수동 자막 수정·재분할·고정된 화면 계획의 렌더·자막 내보내기·초안 생성도 같은 검사를 거친다. 정상 제작의 검토가 빠졌으면 ASR·미디어 작업 전에 중단한다. 알고 있는 금지 경계는 단순 감점이 아니라 거절한다. 원고·보호구·문서·배치·분할 또는 시각이 바뀌면 옛 검토·캐시를 그대로 재사용하지 않는다.

기존 파일과 계획은 자동 변경하지 않는다. 과거 계획의 명시적 재출력은 보존된 원본 경로·SHA와 사유가 있는 별도 이력으로 구분하며, 새 의미 검토를 통과했다고 표시하거나 정상 신규 제작의 면제 수단으로 쓰지 않는다. 파일 SHA는 어떤 입력과 검토가 연결됐는지 검사하는 수단이다. 실제 의미 이해·청감·최종 가독성이나 권한 인증을 증명하는 값이 아니다. 제작 담당자는 새 최종 화면에서 의미 연결과 발화·자막 시각을 확인한다.
