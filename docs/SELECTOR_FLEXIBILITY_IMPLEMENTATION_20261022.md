# 짧은 구간의 주요 원본 연장·연속 배치 개선

## 사용자 지시와 범위

사용자는 약1초 대사에 별도 장면을 찾다 멈추기보다 기존 주요 후보의 자연스러운 원본 구간을 조금 늘려 사용하도록 지시했다. 2026-10-18 `editorial_montage_policy.md`의 정상 속도 연장·자막 조각과 화면 컷 분리·전체 흐름 QA 원칙을 이번 필수 프레임 선택 실패 경로에도 연결한다. 뉴발란스 완성본·현재 QA와 다른 중지 작업을 보존하며 새 영상 제작·수집·전체 제작 재시험은 실행하지 않는다.

## 코드 변경

- `hotpost/scene_requirements.py`: 후보 조각의 길이뿐 아니라 실제 필수 프레임과 출력 컷 길이를 담을 수 있는지 계산한다. 맞지 않으면 같은 실제 원본의 더 긴 승인 구간을 사용하고 다른 승인 구간도 후보로 유지한다. 기존 상위 후보가 하나 있다는 이유로 대체 범위 탐색을 건너뛰지 않는다.
- 정상 편집 정책에서는 앞/뒤 제품 화면과 같은 원본의 연속 시간으로 다음 대사 화면을 연결할 수 있다. 대본·음성·자막/cue 시각은 바꾸지 않고 화면 선택만 이어 붙인다. 현재 요구에 승인된 의미 근거와 실제 구간별 화면 검토 범위가 제안 구간을 포함해야 한다. 최소 원본 사용 수를 잃는 연결은 다른 후보로 넘긴다.
- 실제 필요한 구간이 승인 범위보다 길면 기존 `EditorialWindowGap` 경로로 현재 원본 인접 구간 검토를 요청한다. `hotpost/studio_runtime/editing.py`는 요청한 실제 범위로 기존 연장 기능을 호출하고, 사용 범위 변경 후 현재 대사의 장면 근거를 갱신해 같은 job으로 이어간다. 기존 승인/실패 QA 이력은 보존하며 동일 물리 범위 반복 방지는 유지한다.
- 명시된 정상 편집 정책에서 허용한 소스 재사용은 추가 시간 겹침만으로 중단하지 않고 근거/초를 기록한다. 반복감과 자연스러움은 현재 실제 최종 파일 QA가 판단한다. 재사용을 허용하지 않은 정책에는 적용하지 않는다.
- 실제 파일·원본 SHA·승인 범위·핵심 프레임·의미/역동작·워터마크·최종 QA 보호는 유지한다. 선택 helper도 실행 계약 지문에 포함한다.
