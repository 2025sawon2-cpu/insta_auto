## 이번에 발견한 오류와 수정

1. **제품명 초기 fallback이 남음.** 실제 원본/수집 근거의 중심 명사가 나중에 확인돼도 `accept_source_round`가 기존 product가 비어 있을 때만 갱신했다. 명시 사용자 `product_override`는 유지하고, 실제 원문 근거로 해결한 명사만 갱신한다. 제목·기존 product를 다시 fallback으로 넣어 확정 근거로 승격하지 않는다. 이전 값은 product_resolution_history에 보존한다.
2. **음성 레퍼런스 집필의 프레임 누락.** 긴 발화가 있는 원본은 화면문구 OCR 검수 경로를 타지 않아 `reference_text_evidence`가 없고, 기본 집필 제출에도 이미지가 없었다. 발화/OCR 계약은 유지하고 speech 집필에 별도의 실제 원본6프레임을 연결한다. 원본·시각·프레임SHA cache를 검증하고 소실/변조 시 새 모델 호출 전에 거부한다. 이번 실제 집필에는 같은 형식의 실제6프레임을 명시 전달해 원고/TopPick 모두 검토했다.
