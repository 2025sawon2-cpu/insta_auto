# 게시물 카드 AI 제작 현황

2026-10-19 적용. 터진 게시물 카드의 작은 제작 배지를 현재 작업 패널로 교체했다.

- 실제 실행 중인 제작 job 또는 담당 AI의 실행 중인 모델/도구를 표시한다. 과거 last_action만으로 움직임을 만들지 않는다.
- 소스·대본·음성·편집·검수 5개 단계를 작게 표시하고, 현재 작업명과 한 줄 설명을 함께 제공한다. 임의의 완료율은 표시하지 않는다.
- 실행 중에는 보라색 파형·상태 점·단계 트랙이 움직인다. 완료는 초록 체크, 대기/확인 필요는 황색, 제작 전/중지/연결 확인은 중립색이다.
- 기존 4초 목록 갱신을 사용한다. 요청 제한은 9초이며 마지막 성공 응답으로부터 15초가 지나면 연결 확인으로 바꾸고 동작 표시를 중단한다.
- reduced-motion 설정에서는 애니메이션을 중단한다. 텍스트와 상태 색상은 유지된다.
- 기존 제작 결과도 표시하며 과거 영상에 검수 영수증이 있다고 추정하지 않는다.

핵심 파일: hotpost/video_agent_activity.py, hotpost/video_agents.py, web/agent-status.js, web/agent-status.css, web/app.js, web/index.html.

검증: Node 카드/제작실 30개 테스트, Python 활동/통합/목록 투영 26개 테스트 통과. 실제 로컬 페이지에서 오리·인덕션 완료와 미역국 AI 판단 중 상태를 확인했다. 브라우저 콘솔 오류 없음. 화면 증거는 data/top3-recovery-20261019/agent-ui-live.jpg.

UI 검증 중 수집용 Chrome·VoiceBench는 재시작하지 않았다. 서버 배포는 큐 유휴 확인 및 기존 상태 행 보존 검사를 거쳤고, 미역국 작업은 배포 후 재개했다. 배포 영수증은 data/top3-recovery-20261019/deployment-agent-ui-1에 보관한다.
