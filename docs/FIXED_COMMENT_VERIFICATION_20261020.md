# 고정 댓글과 완성 영상 연결 확인 — 2026-10-20

사용자 최신 요청으로 원작 댓글 키워드의 조회·추출·전송 조건 사용을 제거했다.
요청 댓글은 **나도**로 고정한다. 이는 직전 자동 입력 구현의 원작 키워드/모든 댓글
분기보다 우선한다. 과거 댓글 시도·실패·수신 상품·리틀리 기록은 보존한다.

## 반영

- `post_publish.COMMENT_KEYWORD`를 공통 값으로 사용한다. 목록 표시, 저장 계정 실행,
  자동 완료 후속 실행, 상품 확인 서비스와 브라우저 전송 경로가 같은 값을 사용한다.
- 원작 키워드 추출 함수와 해당 DB 조회를 제거했다. 상품 식별을 위한 원작 본문
  증거 사용은 유지한다. 원작에 다른 키워드가 있거나 키워드가 없어도 요청 문구는
  바뀌지 않는다. DM이 오지 않는다고 다른 키워드로 다시 댓글하지 않는다.
- `GET /api/monetization/{task}/preview`와 화면의 **연결만 확인**을 추가했다.
  실제 검수 완료 영상/계획/대본 SHA와 저장 계정의 실행 매핑만 검사한다.
  조회로 작업을 준비하거나 댓글·DM·게시·리틀리 생성을 시작하지 않는다.
- 구형 서버가 원작 키워드 방식으로 실행하지 않도록 화면은 고정 댓글 지원 여부도
  확인한다. 버튼의 배경·글자색을 명시해 실제 어두운 테마에서도 이름이 보이게 했다.

## 검증과 적용

관련 검사 **107개 통과**. 원작의 다른/복수/누락 키워드와 무관하게 고정 문구를
사용하고, 원작 키워드 DB가 없어도 동작함을 확인했다. 저장 계정 재접속·다른 계정
오연결 거부·실제 파일을 사용한 읽기 전용 preview·기존 중복 방지 회귀를 포함한다.
격리 fixture의 계정 연결 성공을 실제 사용자 계정 연결 성공으로 보고하지 않는다.

후속 전용 3235 서버의 새 리스너 PID **45052**, 관련 모듈 **11개**의 로드 SHA를
확인했다. 메인 제작 서버·브라우저·VoiceBench와 기존 작업은 재시작하지 않았다.
수익화 DB 전후 행/SHA는 동일하고 외부 effect 추가는 **0건**이다.

메인 8775 프로세스는 집필 running 1건/queued 2건과 제작 queued 2건이 있어
재시작하지 않았다. 메인 백엔드의 새 고정 댓글 계약 로드는 아직 미확인(응답에
`comment_keyword` 없음)이며 실제 자동 후속 설정은 꺼져 있다. 운영 적용 확인은
현재 사용자 페이지인 3235에 한정한다. 메인 자동 완료 소비자는 유휴 시점에
새 코드로 로드 확인한 뒤 활성화해야 한다.
