## 남은 개선 항목

1. **핵심 제품을 유지하는 부족분 탐색 확장**: 상세 조건 완화 → 확인된 현지 표기/제품·모델 표현 → 다음 결과·다른 플랫폼·기존 보관본으로 확대하는 전체 흐름은 아직 구현·실증하지 않았다. 같은 검색·부적합 원본을 반복하지 않고, 일반 제품 검색으로 핵심 제품 조건을 몰래 대체하지 않아야 한다. 새 검색어가 실제 적합 원본 확보량에 도움이 되는지도 후속 실제 수집에서 측정해야 한다.
2. **단순 수정 재제작의 비용 축소**: 같은 제품의 소스1개 제외에서도 새 run 검색 실적 확인과11개 장면의 중복 관찰이 발생했다. 중복 관찰2호출의 실제 처리시간은78.47초였고 부모 관찰은29/29 재사용 가능한 것으로 독립 검증됐다. 검색·제품·정책·프레임의 실제 서명이 같은 경우에만 영수증과 관찰을 안전하게 승계하는 개선이 남아 있다. 과거 검색을 새 실제 검색으로 재표기하거나 인물 분류 규칙으로 확대하지 않는다.
3. **계획 변경 직후 소진 상태 재계산**: preflight가 이전 검색어 묶음의 소진 상태를 읽고 새 묶음 생성 후 같은 회차에서 다시 계산하지 않아 첫 전환 회차가 늦어졌다. 해당 회차79.81초에는 필요한 계획·독립 검토 시간도 포함된다. 검색어 묶음 지문에 scope 소진을 결속하고 변경 시 소진 판단만 갱신해야 한다. CAPTCHA·로그인·429 접근 장벽은 이 처리로 해제하지 않는다.

등장인물 관련 전역 자동 분류 규칙은 추가하지 않았다. 사용자 지정 몽벨 첫 소스 제외는 기존 v3 결과에 반영·검증돼 있다.
