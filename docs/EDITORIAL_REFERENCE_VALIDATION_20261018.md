## 기준이 실제로 어떻게 적용되었는가

모델은 주방 매트의 세척·교체·완성 주방 장면, 미니 파일 홀더의 제품·보관 상태, 니트의 착장·디테일 재등장, 테이블 박스의 실내 설명과 야외 사용 반복을 모두 자연스러운 제품 소개로 평가했다. 반복된다는 이유나 새로운 정보가 없다는 이유만으로 차단하지 않았다.

Holdout에서도 같은 기준이 유지됐다. 벽 행거는 걸이를 펼침·물건을 건 사용 상태·접힌 벽 장식 상태의 흐름을 평가했고, 도어 스토퍼는 같은 기능을 반복해 보여주는 설치와 사용 확인을 통과시켰다. 펫 공기청정기는 반려동물·청소 상황에서 제품과 포집된 털로 이어지는 흐름과 후반 제품 재등장을 허용했다. 자동 타코야끼 기계 응답은 “가족 반응과 기계 화면의 반복도 자연스러운 흐름을 유지한다”고 명시했다.

원작의 creator watermark, 얼굴 또는 사진 속 얼굴이 있는 소스 첫 프레임, 신규 제작의 두 줄 문구와 다른 원작 형식은 `project_contract_deviations`로 분리됐다. 이것이 신규 제작에서 허용된다는 뜻은 아니다. 원작의 제품 전달력과 우리가 만들 영상의 커버·가림 계약을 구별한 결과다. 실제 별도 업로드 Instagram 포스터는 제공되지 않았으며 그 포스터의 품질을 평가했다고 주장하지 않았다.

전체 시퀀스 응답을 최종 승인으로 삼지 않고 독립 상세 확인을 추가한 결과, 실제 잘못된 제품 관계를 놓친 1건을 확인했다. 이는 문장마다 장면을 완벽히 맞추라는 요구나 색상·SKU 차이의 과잉 탈락이 아니다. 동일 제품의 앞 서랍을 열어 나온 필터처럼 다른 구조의 필터 시연을 직접 이어 붙인 구체적인 제품 관계 문제다. 통과를 만들기 위한 정책 수정은 없었으며 상세 확인도 같은 동결 지침을 사용했다.

## 공기청정기 반례의 독립 상세 확인

독립 검수자가 기존 실제 시퀀스의 기기 구조 차이를 확인한 뒤, 원시 pass/fail 결론이나 브랜드 차이 주장을 새 모델 입력에 주입하지 않았다. 원문 전체·ref-2/3/4 문맥·기존 전체 시퀀스와 원본 6.5–11초에서 새로 추출한 17개 native 프레임을 제공했다. ffmpeg showinfo의 실제 source PTS와 각 프레임 SHA를 저장했다. 중립적으로 동일 기기의 연속 시연인지, 별도의 맥락 장면인지, 정체성이 확인되지 않는지를 검토하도록 했다.

새 응답은 `passed=false`, `kind=scene_gap`, `beat_id=ref-3`이다. 6.766667–8.366667초는 사각 HEAPETS 기기의 전면 패널과 손을 보여주며 내부 필터는 드러나지 않는다. 8.633333–10.233333초는 세로 격자의 원통형 본체 옆에서 별도의 원통형 망 필터에 붙은 털을 떼는 장면이다. 실제로 두 구조의 연결은 확인되지 않는데, “이 공기청정기 앞 서랍을 열면”이라는 한 문장의 직접 시연으로 이어져 사각 제품에서 그 필터를 꺼냈다고 이해하게 한다는 판정이다. 이는 새 정책이 계속 검토하는 실제 다른 제품·부품의 직접 시연 오인에 해당한다.

동일 응답은 ref-4의 11.5–12초 편히 쉬는 반려동물 컷을 `allowed_mismatches`로 명시적으로 허용했다. 일반 편익과 사용 환경을 지원하는 맥락 컷이며, 정지 표본이 실제 소음 성능을 입증한다고 보지는 않았다. 따라서 상세 확인은 비문자적 지원 장면을 모두 탈락시키는 옛 엄격 기준으로 되돌아간 결과가 아니다.

추가 증거·새 요청 문맥·원시 새 응답은 `reference-review/DeY776gqIQw/targeted-continuity/`의 `native-evidence.json`, `request-context.json`, `review.json`, `run.json`에 있다. 원래 10개 `calibrated-review.json`과 동결 정책은 변경하지 않았다. `validation-summary.json`은 raw broad 결과 10/10과 최종 상세 확인 9/10을 별도 필드로 기록한다.

## 확인 한계

입력은 실제 영상에서 추출한 0.5초 간격 정지 표본과 전사다. 모델은 컷·가림 경계의 모든 k-1/k/k+1 프레임, 표본 사이의 연속 동작, 실제 자동 회전·소음·오디오 청감을 검증했다고 주장하지 않았다. 이 제한은 응답 요약과 일부 advisories에도 명시됐다. 틈새 청소 도구와 벽 행거의 경계 표본 부족은 advisory로 남았다.

처음 전체 시퀀스 10개 응답의 `allowed_mismatches`는 모두 빈 배열이었다. 추가 독립 상세 확인에서야 구체적인 잘못된 제품 연결과 허용되는 맥락 컷을 함께 구분했다. 따라서 단 한 번의 전체 개요 pass만으로 실제 제품 동일성·부품 관계를 확정하면 안 된다. 이 9개 역시 해당 증거에서 차단 결함을 관찰하지 않았다는 의미이며 모든 프레임의 무결성 보증은 아니다. 원작 평가는 이후 새로 제작할 세 영상의 실제 렌더·커버·가림·최종 QA를 대신하지 않는다.

실제 다른 제품을 같은 시연으로 연결하는 문제는 완화 대상이 아니다. 추가 확인은 독립 관찰과 일치했으며 해당 공기청정기는 실제 결함 반례로 보존한다. 새 제작 결과는 같은 기준으로 실제 픽셀과 제품·부품 관계를 별도 검토해야 한다.
