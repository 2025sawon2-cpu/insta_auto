리틀리 · Chrome 저장 로그인
등록·삭제와 입력 변경은 아래 ‘연결 정보 저장’을 눌러야 반영돼요. 삭제해도 Instagram 계정이나 리틀리의 실제 연결은 해제되지 않아요.

리틀리 로그인은 Chrome 자동완성으로

계정별로 Chrome에 저장된 로그인 ID 또는 이메일을 지정해 주세요. 업로드할 때 기존 로그인을 재사용하고, 전환이 필요하면 해당 저장 계정의 자동완성을 사용해요. 계정 등록 후 나중에 입력해도 돼요.

비밀번호는 Chrome에서 관리해요. 이 화면에서는 로그인에 사용할 계정만 저장하며, 실제 리틀리에 연결된 인스타 계정은 업로드 전에 확인해요.
